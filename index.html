智数 — 基于 NL2SQL 的账目管家

LangGraph · Qdrant · Elasticsearch · IK Analyzer · SQLAlchemy · BGE-large-zh · jieba · Qwen2.5
企业数仓复杂 SQL 查询耗时数小时甚至数天。搭建 NL2SQL 问答系统，自动完成语义理解、字段召回、SQL 生成与检验，让业务人员通过对话查数据。
主要职责
  • 智能体编排：基于 LangGraph 搭建 DAG 工作流，跑通「提取关键字 → 多路召回 → 数据整合 → 过滤 → SQL 生成 → 校验 → 执行」全链路。
  • 元知识库构建：字段名/指标名/描述/别名用 BGE-large-zh 向量化入 Qdrant，字段值入 ES 倒排索引并配置 IK Analyzer。

  • 数据补全与过滤：按表名整合字段指标，补主外键，Qwen3.5 识别剔除冗余，补充数据库信息与日期。
  • SQL 生成与检验：Qwen2.5 生成 SQL，MySQL EXPLAIN 校验，失败信息回传 LLM 重新生成并设兜底防死循环。
